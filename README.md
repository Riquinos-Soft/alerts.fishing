# alerts.fishing

`alerts.fishing` es un producto independiente para convertir condiciones ambientales y contexto local en una decisión pesquera explicable: dónde, cuándo y cómo pescar, con qué confianza y bajo qué restricciones de seguridad.

El problema no es la falta de datos meteorológicos genéricos, sino la dificultad de transformarlos en una recomendación local que un pescador pueda entender, evaluar y mejorar con el resultado de sus sesiones.

## Alcance inicial

La primera validación se centra en la lubina europea mediante spinning desde costa en Rías Baixas, con un horizonte de 72 horas y tres spots de demostración: Aguete, Praia do Santo (Seixo) y Placeres/Lourizán. El primer vertical slice utilizará datos mock identificados como tales.

## Estado

**Estado: `decided` — documentación inicial.** El repositorio todavía no contiene una aplicación funcional. El stack y la arquitectura descritos en la documentación son una dirección prevista, no una implementación existente.
