## Español

`alerts.fishing` ayudará a decidir cuándo, dónde y cómo pescar, explicando las condiciones, preparando el equipo adecuado y aprendiendo de la comunidad. Empezará en Galicia y crecerá progresivamente.

El reto no es mostrar más meteorología genérica, sino convertirla en una decisión pesquera local, comprensible y evaluable.

> **Estado actual:** producto especificado y en diseño. La aplicación todavía no está implementada.

### Lo que queremos construir

- [x] Galicia definida como territorio inicial.
- [ ] Mapa de spots y oportunidades de pesca.
- [ ] Mejores horas con explicaciones de las condiciones.
- [ ] Especies, temporadas, vedas y normativa por zona.
- [ ] Alertas personalizadas.
- [ ] Equipo recomendado, tutoriales y nudos paso a paso.
- [ ] Comunidad para compartir capturas de forma segura.
- [ ] Aplicación web y futuras versiones para iOS y Android.
- [ ] Ampliación progresiva al resto de España.

### Alcance inicial

La primera validación se centra en la lubina europea mediante spinning desde costa en Rías Baixas, con un horizonte de 72 horas y tres spots de demostración: Aguete, Praia do Santo (Seixo) y Placeres/Lourizán. El primer vertical slice utilizará datos mock identificados como tales.

## English

`alerts.fishing` will help anglers decide when, where and how to fish, understand the conditions, prepare the right gear and learn from the community. It will start in Galicia and expand progressively.

The goal is not to display more generic weather data, but to turn it into a local fishing decision that is easy to understand and evaluate.

> **Current status:** product specification and design. The application has not been implemented yet.

### What we want to build

- [x] Galicia defined as the initial territory.
- [ ] Fishing spots and opportunity map.
- [ ] Best fishing windows with clear condition explanations.
- [ ] Species, seasons, restrictions and local regulations.
- [ ] Personalized alerts.
- [ ] Gear recommendations, tutorials and step-by-step knots.
- [ ] A safe community for sharing catches.
- [ ] Web application and future iOS and Android versions.
- [ ] Progressive expansion across the rest of Spain.

### Initial scope

The first validation focuses on European seabass and shore spinning in Rías Baixas, with a 72-hour horizon and three demonstration spots: Aguete, Praia do Santo (Seixo), and Placeres/Lourizán. The first vertical slice will use data clearly identified as mock data.
